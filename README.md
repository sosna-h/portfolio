# Sosna Hailu — Portfolio

A full-stack personal portfolio built with React, Node.js, Express, and MySQL.

## Tech Stack

- **Frontend:** React 18, Vite, CSS Modules
- **Backend:** Node.js, Express
- **Database:** MySQL

## Project Structure

```
portfolio/
├── frontend/   # React + Vite app
└── backend/    # Express API server
```

## Local Development

**Backend** (Terminal 1):
```bash
cd backend
npm install
npm run dev
```

**Frontend** (Terminal 2):
```bash
cd frontend
npm install
npm run dev
```

Frontend runs at `http://localhost:5173`, backend at `http://localhost:5000`.
